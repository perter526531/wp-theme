# 设计系统规范(A×B 组合,已确认方向)

> 状态:2025-09-28 用户确认采用 **A×B 组合**。本文档是后续 WordPress 主题开发的视觉规范依据。
> 高保真首页演示:预览环境 `/`(Hi-Fi Mockup v1)。

## 1. 设计哲学

**深色展示说服 + 浅色阅读信任,一套系统,两种节奏。**

- **A 区(展示说服型)**:深色科技感,用于需要制造"哇"时刻、建立技术信任的页面区域
- **B 区(阅读信任型)**:浅色国际感,用于长时间阅读、表单填写、建立稳健印象的页面区域
- 全站共享同一字体系统、栅格、组件规范与圆角语言,保证品牌统一

## 2. 色彩令牌

### 基础色板
| 令牌 | 色值 | 用途 |
|------|------|------|
| `--deep` | #062A33 | A 区背景(深海墨青) |
| `--deep-2` | #05242E | A 区加深层(数据条/页脚前层) |
| `--deep-3` | #041E26 | 页脚(最深) |
| `--cyan` | #00C2D1 | A 区强调色(冰川青:图标/链接/动效) |
| `--cyan-deep` | #00A8B8 | 动效描边(对比加深) |
| `--amber` | #FFB454 | CTA 按钮(琥珀橙,A/B 区通用) |
| `--amber-hover` | #FFC46B | CTA 悬停 |
| `--ink` | #1C2B33 | B 区正文标题(石墨) |
| `--ink-muted` | #5B6B73 | B 区次要文字 |
| `--paper` | #FFFFFF | B 区背景 |
| `--paper-alt` | #F6FAFB | B 区交替背景 |
| `--teal` | teal-700 系 | B 区强调(图标/链接) |

### 使用规则
1. CTA 永远是琥珀橙实底 + 深青文字,全站唯一,不与其他按钮竞争
2. A 区文字:主 #FFFFFF,次 rgba(stone-300);B 区文字:主 #1C2B33,次 #5B6B73
3. 禁止在 B 区大面积使用深青色块(会破坏节奏);深色只属于 A 区
4. 语义色:成功 teal-700 / 警示 amber-500 / 错误 red-600(表单用)

## 3. 字体系统

| 层级 | 字体 | 说明 |
|------|------|------|
| 西文标题 | Space Grotesk | 几何感科技无衬线,`.font-display` |
| 西文正文 | Inter | 屏幕可读性标杆 |
| 中文(后续语言) | Noto Sans SC | 与西文字重对齐 |

- **WordPress 主题中全部自托管**(woff2 本地化,不依赖 Google Fonts 海外可用性;预览环境用 next/font)
- 字号阶:H1 `36-60px` / H2 `24-36px` / H3 `16-18px` / 正文 `14-16px` / 辅助 `11-12px`
- 眉题(eyebrow):`12px / 700 / 0.22em 字距 / 大写`——A 区用冰川青,B 区用水鸭青
- 现有 Logo 字标含 "HIGH-END ICE & HEAT TECHNOLOGY SPECIALIST" 定位语,可作 Hero 眉题复用

## 4. 布局与栅格

- 容器:`max-w-7xl`(1280px)`mx-auto px-4 sm:px-6`
- 区块垂直节奏:`py-16 sm:py-24`
- 卡片圆角:`rounded-2xl`(16px);大容器 `rounded-3xl`(24px)
- 卡片内边距:`p-5 / p-6`;网格间距:`gap-4 / gap-5`
- 页脚 sticky 规则:`min-h-screen flex flex-col` + `main flex-1` + `footer mt-auto`

## 5. 区块节奏分配(哪些页面/区块用 A,哪些用 B)

| 区块 | 节奏 | 说明 |
|------|------|------|
| 首页 Hero | A | 网格纹理 + 光晕 + 产品白卡 + 速热仪表 |

## 6. 组件规范(摘要)

- **按钮**:CTA 实底琥珀(圆角全弧 `rounded-full`,py-3 px-6,粗体);次按钮描边(白描边 on A / teal 描边 on B)
- **产品卡**:白底 + `aspect-square` 图区 + 底部信息条(型号 font-display 粗体 / 分类 11px / Inquire 链接)+ 悬停上浮阴影;NEW 徽标琥珀
- **场景/卖点/技术卡**:图标容器 44px 圆角方块(A 区 cyan/10 底,B 区 teal-50 底)+ 标题 + 描述 + 链接;悬停 `-translate-y-0.5` + 阴影
- **案例卡**:地区徽标(深底白字 + MapPin)+ 标题 + 一句话 + 指标 chips
- **chips**:圆角全弧、11-12px、A 区 `border-white/15 bg-white/5`、B 区 `bg-stone-100`

## 7. 动效原则

1. **「3 秒速热」仪表**:SVG 进度环 3s 升温(25→95℃)+ 1.2s 保持循环,白色卡片悬浮于 Hero 产品图左下——已确认核心模块①
2. 悬停位移不超过 2px(`-translate-y-0.5`),阴影渐变 200-300ms
3. 图片缩放悬停 `scale-105` + 300ms(产品卡)
4. 动效服务信息传达(温度上升=即热),不做纯装饰动画
5. 遵循 `prefers-reduced-motion` 无障碍偏好(开发期实现)

## 8. 图片规范

- 产品图:白底方图(1024×1024 优先),`object-cover` 入 `aspect-square` 容器
- Banner:1920×800,`object-cover` + 圆角容器
- 现阶段使用原站素材(见 ia-structure.md §6 素材清单);上线前建议补拍统一光效产品图
- 所有图片必须有描述性 alt(型号 + 品类)

## 9. 无障碍要求

- 语义化标签(header/main/section/article/footer/nav/address)
- 装饰元素 `aria-hidden`,图标按钮 `aria-label`
- 触控目标 ≥ 44px(移动端按钮 py-3 起)
- 文字对比度:深底白字 ≥ 4.5:1;琥珀按钮深青字 ≥ 4.5:1
