## 1. 公司主要业务

Dazhen Tech(大振科技)是一家位于广东惠州大亚湾的**智能饮水设备制造商**:

- 自主研发即热(纳米稀土厚膜加热)、即冷、冷热一体化等核心技术与产品
- 以 **OEM/ODM 一站式服务**为主要商业模式,为全球品牌商、经销商代工定制
- 同时提供面向不同场景的饮水解决方案(家庭、办公、教育医疗、酒店工程)
- 2018 年启动全球化战略,产品通过国际认证批量出口(案例覆盖英国、泰国等市场)

### 核心技术卖点
- 3 秒速热、恒温出水(厚膜加热+智能温控)
- 即热即冷一体化(行业首创)
- UV 杀菌 99.99%、RO 反渗透
- 富氢水、凉白开、气泡水等健康饮水技术
- AI 温控芯片、智能大屏、杯型识别

### 服务(OEM/ODM 一站式)
- 7 步流程:需求沟通 → 概念开发 → 规格确认 → 打样测试 → 生产质控 → 包装出货 → 交付后支持
- 4 大优势:完全定制 / 更快上市 / 全球合规(ISO、BSCI)/ 经验丰富的团队
- 商务条款:MOQ 100 件起、定制周期 4–6 周、1 年质保、全球售后
- FAQ 分四组:产品相关 / OEM-ODM 相关 / 售后 / 支付与物流

## 4. 网站主要目标

**B2B 海外获客官网,核心目标是询盘转化(Get a Quote / Send Inquiry),而非线上零售。**

支撑目标:
- 用技术实力(专利、自研技术)建立专业信任
- 用产品矩阵证明"全场景覆盖"能力
- 用发展历程(2012–2025 时间线)证明企业稳定性和积累
- 用成功案例(国家、数量、金额、客户反馈)降低采购决策风险
- 用解决方案内容做场景化引导,匹配不同客户群的搜索意图

## 5. 网站需要重点展示的信息(按重要性排序)

7. **场景化解决方案**(四大场景)

### 原站存在的内容/体验问题(新站要解决)
1. 头部展示的是主题演示占位地址(304 North Cardinal St., MA)而非真实地址
2. 部分产品名是 Lorem ipsum 占位文本(consectetur adipiscing 等)
3. 产品详情页没有结构化参数表
4. 解决方案是博客文章,不是独立着陆页,场景化引导弱
5. 版权年份硬编码、个别文案笔误
6. 询盘表单分散在 Services 和 Contact 两处,字段不一致(Services 7 字段 / Contact 4 字段)
