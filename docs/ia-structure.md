## 2. 站点地图(v3,7 个顶级板块)

```
1. 首页 Home
2. 关于我们 About Us(简介/时间线/技术/资质/工厂)
3. 产品中心 Products
   ├── 产品列表页(系列筛选 + 搜索)
   ├── 产品详情页(图集/卖点/参数表/相关产品/询盘 CTA)
   └── 10 个系列分类页
4. 解决方案 Solutions ★含成功案例(v3 核心变更)
   ├── /solutions/ 总览页:4 场景入口 + 成功案例库(按地区/场景筛选)+ 全球交付地图
   ├── 4 个场景着陆页(家庭 / 办公商业 / 教育医疗 / 酒店工程)
   │    每页结构:场景痛点 → 方案构成 → 推荐产品 → 相关案例 → 询盘 CTA
   └── 案例详情页(结构化模板:客户国家/类型/订单量/挑战/方案/反馈)
5. 服务与定制 Services(OEM/ODM 流程/优势/FAQ/询盘)
6. 新闻资讯 Blog
   ├── 公司新闻 Company News
   └── 行业新闻 Industry News
   (案例内容已移入 Solutions;Blog 只保留两类)
7. 联系我们 Contact Us(联系信息/统一询盘表单/地图可选)
```

### v2 → v3 变更明细
| 项目 | v2 | v3 |
|------|----|----|
| Cases 板块 | 独立顶级板块(8 个顶级) | **并入 Solutions**(7 个顶级) |
| Blog 分类 | 公司/行业/案例 三类 | 公司/行业 两类 |
| 全球交付地图 | 位于 Cases 板块 | 位于 Solutions 总览页 |
| 首页"精选案例"区 | 独立板块 | Solutions 区块内的 Success Stories 子区 |
| 案例筛选维度 | 地区/场景/产品 | 地区/场景(简化,与 Solutions 场景对齐) |

**保留的 SEO 考量**:案例详情页 URL 建议 `/solutions/cases/{slug}/`,继续享受独立收录;
首页 Solutions 区块内嵌 Success Stories 卡片,形成"场景 ↔ 案例"双向内链。

## 4. 多语言策略(已确认)

- **首发语言:英文(en)**——默认语言,面向全球买家

- 若未来包含 RTL 语言(阿拉伯语等),需追加 RTL 布局支持(暂不做)
